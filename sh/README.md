# dh/sh

A `curl`-able, terminal-friendly version of my personal website (<https://sh.dallinhuff.com>).

Technically, it's a rust CLI for generating static text pages.
Definitely overengineered, but nice to have flex-box-style formatting for rendering text to the terminal.

## Prerequisites

- Rust Toolchain (<https://rust-lang.org/tools/install/>)
    - I recommend [using a package manager][rustup-pkgman] over the default `curl | sh` install method, but you do you :shrug:
